# ensf337-group7-fmas
FMAS (Flight Management Application System), the ENSF 337 Fall 2026 term project by Group 7: Parin, Agastya Parashar, and Aditya Patel. It’s a menu-driven C++ console app that loads flights and passengers from text files, shows seat maps and passenger lists, adds and removes passengers, and saves changes back to file.
